# Vermut — Design Tokens & UI Spec (v2)

> Generated by `build/design_md.py` from `tokens/tokens.json`, `tokens/contrast.json` and `swiftui/VermutColors.swift`. Do not hand-edit values; edit `build/palette.py` and regenerate. Approved by the owner on 19 Oct 2026 (light-background icon is primary).
> Values marked **(defined here)** did not exist as tokens before this spec; they are codified from the v2 mockups (`mockups/*.html`) and are now normative.

## 1. Brand context

**Vermut** is a free, open-source macOS app (SwiftUI) that installs and launches Steam, Epic Games Store and GOG Galaxy through Wine on Apple Silicon. Each store lives in its own Wine prefix, called a **bottle**. The name is a nod to Wine (as Whisky did). Claim: **"Pour. Click. Play."** — always English, never translated, punctuation as written.

Values: open source · free · easy · Windows games on Mac.

### Hard rules

| # | Rule |
|---|---|
| R1 | UI is neutral, shadcn-style, Zinc greys. Chrome never competes with game art or store logos. |
| R2 | Brand red (`brand-*`, `#CE003E`) appears **only** in the logo (sidebar mark, About, app icon) and marketing. Never on buttons, links, toggles, selection, focus rings, progress, tints, or `.accentColor`/`.tint`. |
| R3 | Red inside the UI means **error/destructive only** (`destructive`, `error-*`). |
| R4 | Status is semantic: success = green, warning = amber, error = red, info/in-progress = blue, idle = neutral. Never color-only: always text and/or icon. |
| R5 | No aperitivo references anywhere (glasses, olives, citrus, "cheers", cocktail copy/emoji). "Bottle" is a technical term (Wine prefix). |
| R6 | Primary action = zinc (`primary`): zinc-900 on light, zinc-200 on dark. One primary per card/view. |
| R7 | App accent color (`AccentColor` in the asset catalog) must be neutral (set to `primary`) — not red, not system blue default for chrome. |

| Bottle detail | header (56 logo, title, path in mono, actions right) · tabs · two columns: form (flex) + side column 320 |
| Onboarding | split: left panel 440 (`sidebar` bg, icon 128, padding 40) + right steps panel (padding 96/64/40) |

### 4.7 Motion **(defined here)**

| Use | Duration | Curve / SwiftUI |
|---|---|---|
| Hover / pressed state | 100 ms | `.easeOut(duration: 0.1)` |
| Toggle, segment, selection, badge state change | 150 ms | `.snappy(duration: 0.15)` |
| Panel/sheet/content transitions | 200–250 ms | `.smooth(duration: 0.25)` |
| Progress value updates | 300 ms | `.linear` (determinate); indeterminate = system `ProgressView()` |
| Reduce Motion on | — | cross-fade only, no movement/scale |

No bounces, no spinning logos, no confetti.

## 5. Component guidance

### 5.1 Buttons

| Variant | Background | Foreground | Border | Use |
|---|---|---|---|---|
| Primary | `primary` | `primaryForeground` | — | the one main action: Install, Open Steam, Play, Continue |
| Outline (secondary) | `background` (dark: white 4%) | `foreground` | `border`/`input` + `shadow-xs` | Cancel, Quit, Retry, Update, Show C: drive, Run .exe |
| Ghost | clear | `mutedForeground` | — | tertiary: “View logs”, “Skip for now”, overflow `…` |
| Destructive (outline) | `background` | `errorSubtleForeground` | `errorBorder` | Delete bottle… (opens confirmation) |
| Destructive (solid) | `destructive` | `destructiveForeground` | — | only the final confirm in a destructive dialog |
| Disabled | any variant at 50% opacity | | | |

Focus ring: 2 pt `ring` (use system focus ring where possible). Never a brand-red button, link or tint.

### 5.2 Badges / status

| State | Variant | Example copy | Icon |
|---|---|---|---|
| Running, Ready, Installed, Supported | success | “Running” | 6-pt dot or `checkmark.circle` |
| Installing x%, Update available, Downloading | info | “Installing · 64%” | spinner / `arrow.down.circle` |
| Needs attention (e.g. DXVK update, low disk) | warning | “Needs DXVK 2.6” | `exclamationmark.triangle` |
| Crashed, Download failed, Not compatible | error | “Download failed” | `exclamationmark.circle` |
| Not installed, Idle | neutral (`muted` bg, `mutedForeground`, `border`) | “Not installed” | — |

Badge = `xSubtle` bg + `xSubtleForeground` text + `xBorder`. Sentence case, ≤ 3 words + optional value. Pair every error with an action (Retry / View logs).

### 5.3 Cards
`card` bg, 1-pt `border`, radius 10, padding 16, internal gap 12. Store card anatomy: logo tile 40 + name (Headline) + badge · description (2 lines, `mutedForeground`) · optional progress · hairline · mono metadata (`bottle/steam · D3DMetal · 1.4 GB`) · actions (one primary, flex-fill). Overflow menu top-right as ghost icon button. Info/tip callout card: `infoSubtle` bg, `infoBorder`, `infoSubtleForeground` text — no colored left-border stripes.

### 5.4 Sidebar
Rows 28 pt, SF Symbol 16 in `mutedForeground` (active: `foreground`), label 13; active row `sidebarAccent` bg + Medium weight; trailing counts 11 pt `mutedForeground`. Bottle rows show the store logo tile (16 pt, radius 4) and a 6-pt `success` dot when running. Logo at top is the only brand-red element in the window. Footer: engine status mini card (mono versions) + Settings row with version in mono.

### 5.5 Progress
Determinate bar 6 pt, track `muted`, fill `info` (not `primary`, not brand); show percentage in mono or in the badge. Storage breakdown bars use neutral steps (`Neutral.s700/s500/s400`) with a legend. Indeterminate: system `ProgressView()`.

### 5.6 Empty states (defined here)
Left-aligned within the content area (not a dashed drop zone): 16-pt icon in `mutedForeground`, Headline, one Body line in `mutedForeground`, one primary button (e.g. Library empty → “Install a store”). If drag-and-drop of `.exe` is supported, the drop target appears only during an active drag (dashed 1-pt `ring` border, radius 10).

### 5.7 Do / Don’t (from the v1 critique)

| Don’t (v1) | Do (v2) |
|---|---|
| Empty checkbox squares as sidebar icons | SF Symbols 16 pt per section (storefront, gamecontroller, arrow.down.circle, gearshape) |
| “S / E / G” letter avatars for stores | Official store logos on their brand tiles |
| Dashed banner that reads like a drop zone but is static text | Static info → info callout card or plain muted text; dashed borders only for real drop targets during drag |
| Lower half of the window empty | Fill with useful content: Activity list, This Mac / storage, Continue playing |
| Claim / marketing copy inside the app UI | Functional copy only (“Each store runs in its own bottle…”) |
| Red accents for selection or primary buttons | Zinc primary; red only for errors/destructive |
| Multiple primary buttons per card | One primary, others outline/ghost |
| Grey cap/brand mark disappearing on dark | Use the `-dark` mark variant (light cap) in dark appearance |
| Off-grid spacing (e.g. 10, 14, 18) | 4/8-pt tokens only |

## 6. UI review checklist
Run against every screen, in light **and** dark appearance, at 1024 × 680 and 1440 × 900.

**Color & semantics**
- [ ] No `Brand.*`, `brand` or `#CE003E` used outside the sidebar logo / About / app icon (grep the codebase for `brand`, `CE003E`, `.red`, `Color.red`, `.tint(.red)`).
- [ ] App `AccentColor` is neutral; no `.tint`/`.accentColor` set to red or brand.
- [ ] Every red pixel in the UI corresponds to an error or destructive action.
- [ ] All colors come from `Color.Vermut.*`; no hard-coded hex/RGB, no `Color.gray`/`.secondary` mixing outside tokens (system `.secondary` label styles are OK only if they match `mutedForeground` intent).
- [ ] Each status uses the correct family (table 5.2) and has text/icon, not color alone.
- [ ] Text contrast ≥ 4.5:1 (check custom combos against §2 values); focus ring visible (≥ 3:1).

**Typography**
- [ ] Only SF Pro / SF Mono; sizes from §3.1 only (26, 22, 15, 13, 12, 11). No 10-pt readable text.
- [ ] Technical metadata (paths, versions, sizes, args, logs) in mono; numbers use monospaced digits.
- [ ] Sentence case for titles, buttons, badges.

**Layout & components**
- [ ] Spacing/padding values from §4.1 only; content padding 24; card padding 16.
- [ ] Radii per §4.2 with `.continuous` style.
- [ ] Control heights per §4.5 (buttons 28/24/36, fields 28, sidebar rows 28, badges 20).
- [ ] One primary button per card/view; destructive actions are outline + confirmation.
- [ ] Sidebar uses SF Symbols, store logos for bottles, running dot, no placeholder squares.
- [ ] Store logos are official marks; no letter avatars.
- [ ] No dashed boxes except live drop targets; no empty half-screens; empty states per §5.6.

- [ ] Full keyboard navigation; visible focus.
